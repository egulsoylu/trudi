# TRUDI: TRansportation Unit Detection and Identification Dataset
The TRUDI dataset is the first publicly available dataset captured from both ground and UAV perspectives, designed for the detection and identification of transportation units such as containers and trailers. This dataset was created as part of the InteGreatDrones project, to advance the development and evaluation of object detection, text detection, and text recognition methods for identifying transportation units.

TRUDI consists of X images collected from inland ports, utilizing various types of cameras, including UAVs, smartphones, and DSLRs. The images were taken on different days and times which provides various weather and lighting conditions. Additionally, the images feature a range of zoom levels, offering both focused and overview images of transportation units and the ports.
