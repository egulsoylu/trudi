# TRUDI: TRansportation Unit Detection and Identification Dataset
The TRUDI dataset is the first publicly available collection of images captured from both ground and UAV perspectives, designed for the detection and identification of transportation units such as containers and trailers. This dataset was created as part of the InteGreatDrones project, to advance the development and evaluation of object detection, text detection, and text recognition methods for identifying transportation units.

TRUDI is consist of X images collected from inland ports, utilizing various types of cameras, including UAVs, smartphones, and DSLRs. The images feature a range of zoom levels, offering both focused and overview perspectives.
